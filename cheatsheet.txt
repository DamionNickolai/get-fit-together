CHANGE BRANCH:
git checkout dev

SWISS ARMY KNIFE TO MAKE CHANGES:
git switch dev

CLOSE APP:
Ctrl + c

QUICK SAVE:
Ctrl + s

CREATE VIRTUAL ENV:
python -m venv venv

CREATE LOCAL .ENV FROM TEMPLATE:
Copy-Item maintenance/.env.example .env

BACKFILL AUTH IDS:
Run locally after setting SUPABASE_URL and SUPABASE_SERVICE_KEY:
python maintenance/backfill_auth_user_ids.py
python maintenance/backfill_auth_user_ids.py --apply

VALIDATE LOCAL MATCHES CLOUD:
git fetch origin dev
git status
VALIDATE ALL CLOUD:
git fetch --all
git branch -vv
STORE AND MERGE LOCAL UPDATES (Do this if you have made changes locally but origin is ahead):
git stash
git fetch origin dev
git status
git stash pop

PUSH A SMALL FIX TO DEV STAGING:
git add auth.py
git commit --amend --no-edit
git push --force origin dev

AUTO PUSH FROM LOCAL TO CLOUD:
python push_to_dev.py
python push_to_prod.py

PUSH_TO_DEV.PY FLOW (UPDATED):
- Fetches origin/dev, switches to dev, and pulls with --ff-only
- Optional APP_VERSION bump in get_fit_together.py (semantic version format)
- Shows current changes and asks to stage all with git add -A
- Commits and pushes to origin/dev

PUSH_TO_PROD.PY FLOW (UPDATED):
- Requires clean working tree (no unstaged/staged changes)
- Fetches origin with prune
- Requires exact confirmation text: deploy prod
- Switches to main, pulls with --ff-only, merges origin/dev with --ff-only
- Pushes main and switches back to your starting branch

INSTALL PACKAGES:
pip install -r requirements.txt

ENTER VIRTUAL ENV:
.\venv\Scripts\activate

RUN APP:
python -m streamlit run get_fit_together.py
